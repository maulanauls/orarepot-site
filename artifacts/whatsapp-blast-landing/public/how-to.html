How to run FE + BE

Urutan start seluruh landing, docs, dan microservices. Postgres + Redis sudah di VPS. Password dan token hanya di file .env — jangan di-commit.

Dua mode

A — tes register cepat: identity Cargo :8101 + FE :5173.
B — seluruh service: docker compose up --build -d (gateway :8080) + kedua FE.
Kalau Cargo identity sudah jalan, stop dulu sebelum compose — port 8101 bentrok.

1. Frontend

Root repo: /Applications/DEVELOPMENT/TIKN

Landing + dashboard — :5173

.env.local → NEXT_PUBLIC_API_BASE_URL. Identity saja: http://localhost:8101. Full stack: http://localhost:8080. Restart npm setelah ganti env. Password daftar minimal 8 karakter. WhatsApp 08xx atau +62.

cd /Applications/DEVELOPMENT/TIKN/orarepot-site/artifacts/whatsapp-blast-landing
npm install
npm run dev

Daftar: http://localhost:5173/register/diorarepot · halaman ini: http://localhost:5173/how-to.html

Docs — :5174

cd /Applications/DEVELOPMENT/TIKN/orarepot-site/artifacts/orarepot-docs
npm install
npm run dev

2. Backend

Mode B — semua service (Docker)

  1. Pastikan Docker Desktop nyala.
  2. Isi orarepot-be/.env dari .env.example. META_WA_TOKEN untuk kirim WhatsApp; WHATSAPP_STUB=true kalau belum mau hit Meta.
  3. Stop Cargo identity jika :8101 sudah terpakai.
  4. Build + up, lalu seed.
cd /Applications/DEVELOPMENT/TIKN/orarepot-site/artifacts/orarepot-be
docker compose up --build -d
make seed

Seed: hello@orarepot.com / orarepot1 · Gateway http://localhost:8080

Postgres/Redis lokal (bukan VPS): docker compose --profile local-infra up -d

Port 8101 Identity Cargo dan container identity sama-sama bind 8101. Cek: lsof -nP -iTCP:8101 -sTCP:LISTEN

Mode A — register saja (tanpa Docker)

cd /Applications/DEVELOPMENT/TIKN/orarepot-site/artifacts/orarepot-be/rust
set -a && source ../.env && set +a
export DATABASE_URL="$DATABASE_URL_IDENTITY" BIND=0.0.0.0:8101 RUST_LOG=info
cargo run -p identity

FE harus NEXT_PUBLIC_API_BASE_URL=http://localhost:8101
